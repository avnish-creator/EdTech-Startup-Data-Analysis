# EdTech-Startup-Data-Analysis
📊 EdTech Recorded Lectures Data Analysis 📌 Project Overview  This project focuses on analyzing data from an EdTech startup aiming to expand its recorded lecture offerings. The goal is to transform raw data collected from multiple EdTech platforms into meaningful insights that drive content strategy, user engagement, and business growth.
Through data cleaning, exploration, and visualization, this project delivers a comprehensive Power BI dashboard that highlights key trends across categories, languages, instructors, and learner preferences.


🎯 Objective

To help the EdTech startup:

Identify high-demand categories and skills
Understand user engagement patterns
Optimize course offerings and accessibility
Make data-driven business decisions

📂 Project Files
Dashboard.pbix → Interactive Power BI dashboard
Project Problem Statement.docx → Business problem and requirements
(Optional) Dataset file → Raw data used for analysis

🧹 Data Preparation
Cleaned missing and inconsistent values
Standardized categories, sub-categories, and languages
Transformed course duration into comparable formats
Prepared data model for efficient dashboarding


📊 Key Analysis & Insights

1. 📚 Course Distribution
Analyzed the number of courses across categories and sub-categories
Identified which domains have the highest content availability

3. 👀 Viewer Engagement
Calculated average views across:
Categories
Sub-categories
Languages

5. 🧠 Skills Demand Analysis
Identified most commonly taught skills
Mapped skills to categories to align with market demand

6. 🌍 Language Distribution
Explored how courses are distributed across different languages
Highlighted multilingual opportunities

7. 🗣️ Language Preference (Top 5 Categories)
Analyzed viewer preferences by language
Focused on top-performing categories to guide content localization

8. 🎬 Subtitles Impact
Studied the relationship between:
Subtitle availability
Number of views
Provided insights into accessibility vs engagement

9. ⭐ Top Instructors
Identified Top 3 instructors per category & sub-category
Based on ratings to highlight high-performing educators

10. ⏱️ Course Duration vs Views
Examined how course length affects engagement
Standardized duration:
Monthly → 60 hours
Flexible → 200 hours

11. 🧩 Skill Variety vs Viewership
Analyzed whether offering diverse skills increases course popularity
📈 Dashboard Features
Category-wise deep dive (primary focus)
Interactive filters (Category, Language, Instructor)
Visual comparisons for engagement metrics
Static visuals for top instructors
Clear storytelling for business decisions

💡 Business Impact

This analysis helps the startup:

Launch high-demand courses
Target the right audience segments
Improve content accessibility (language & subtitles)
Collaborate with top instructors
Increase engagement and viewership

🚀 Conclusion

This project demonstrates how data analytics can drive strategic decision-making in EdTech. By focusing on category-wise insights and user behavior, the startup can scale its recorded lecture offerings effectively and stay competitive in the evolving online education market.
